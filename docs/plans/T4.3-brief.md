# T4.3 — Captions job (brief)

Branch `t4-3-captions`, stacked on `t4-2-tts` (#48).

| ID | Task | Size | Depends | Acceptance criteria |
|---|---|---|---|---|
| T4.3 | Captions job: whisper.cpp runner, word JSON parsing, script-word alignment (Needleman–Wunsch), interpolation, proportional fallback | M | T4.2 | Alignment unit tests on hand-made token sequences (insertions/deletions/number formats); `@pytest.mark.whisper` on a fixture WAV yields monotone non-overlapping timings covering ≥ 95 % of script words |

Decisions made overnight under the owner's go-ahead:

1. **whisper-cli invocation.** `-oj -ojf -ml 1 -sow -np` gives one segment per word with millisecond offsets (verified against whisper.cpp 1.9.5). Input is a 16 kHz mono copy made with ffmpeg.
2. **Alignment.**
   - Per scene, whisper words whose midpoint falls in the scene's `tts.json` range (±0.25 s) are aligned to the script words with Needleman–Wunsch.
   - Scoring: exact +2, partial +1 (difflib ratio ≥ 0.6 or a prefix, so "QN3VL"≈"Qwen3-VL" and "5.4%"≈"5.4"), mismatch −1, gap −1.
   - The on-screen text is always the script's words; only the timings come from whisper.
3. **Interpolation.** Unmatched words are character-weighted between their matched neighbours. A scene with no whisper words, or a whisper failure, falls back to proportional timing inside the TTS range.
4. **Clamping.** Every scene's timings are clamped to be monotone, non-overlapping, inside the scene, and at least 40 ms each (hypothesis property).
5. **No new dependency.** `whisper_bin` is resolved to an absolute path (minimal job `PATH`); the stage takes an injectable transcriber for tests.

**Real run (local, `@pytest.mark.whisper`):** coverage **97.6 %** (165/169 words) on the Kokoro-voiced 6-story template script.

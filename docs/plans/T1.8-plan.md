# T1.8 Plan: Replay and Report

## 1. Summary

T1.8 delivers the tuning loop for the wake engine.  When done:

- `chronos wake replay` re-scores stored or fixture mornings under two rule
  versions and prints a comparison table (with `--json` option).
- `chronos wake annotate <date> --actual HH:MM` records the owner's actual
  wake time in `days.actual_wake_local`.
- `chronos report build <date>` builds a Markdown audit trail of a day's
  evaluations, timeline sparkline, transitions, and anomaly notes.
- `GET /v1/report/{local_date}` serves the Markdown file (or builds on-the-fly)
  as `text/markdown`.
- The scheduler writes the previous day's report once after the 03:00 boundary
  (idempotent, tested with FakeClock).

## 2. Design

**Context helper (Step 1).** `service.py` steps 5–6 that build `PreviousTick`
and `EvalContext` are extracted into `wake/context.py`.  Both `service.py` and
`replay.py` call the same helpers, so scoring parity is structural.

**Replay engine (Step 2).** `wake/replay.py` is pure (no I/O inside `replay_events`).
`load_fixture` reads the JSON array; `replay_events` threads `PreviousTick`
identically to `test_mornings.py` (which is updated to call `load_fixture`).
`replay_db_range` loads `telemetry_events` per-day, skips parse errors, and
re-scores under candidate rules.  `compare()` computes confirm latency and the
early-confirm flag.

**Report builder (Step 3).** `report/builder.py` queries `days`,
`wake_evaluations`, `day_transitions`, `push_notifications`, and
`rule_versions`.  Plain f-strings + markdown tables; sparkline uses `▁▂▃▄▅▆▇█`
on a fixed 0–100 scale.  `write_day_report` writes to `settings.reports_dir`
idempotently (overwrite).

**API endpoint (Step 4).** `GET /v1/report/{local_date}` requires bearer token
(consistent with all other endpoints; reports contain personal wake data).
Returns the file if it exists, else builds in memory; 404 if no `days` row.

**CLI (Step 5).** New `wake_app` and `report_app` Typer subgroups added to
`cli.py`.  Plain-text tables via `typer.echo`; `rich` is a transitive
dependency (`uv tree` confirms `rich v15.0.0`), so `rich.table.Table` is used
for the replay table.

**Scheduler (Step 6).** `run_reports(now, session_factory)` is a new method on
`Scheduler`; called from `run_forever` after every `run_due` cycle.  It checks
if `now` is past the day boundary + 15-minute grace for each active device and
writes the previous date's report if the file does not yet exist.

**Rejected alternatives:**
- Separate `wake/fixture_loader.py` module — folded into `replay.py` (it is a
  single function).
- Caching the report at the API layer — owner answer 5 says no caching; file
  presence is sufficient.
- Rolling the context helper into `scoring.py` — keeping I/O-free scoring
  pristine is the correctness rule.

```python
"""Shared EvalContext-building helpers (T1.8).

Extracted from service.py so that replay.py can build EvalContext with
structural parity — both call the same helpers, not duplicated logic.

Public API
----------
- :func:`make_previous_tick_from_row` — build PreviousTick from ORM rows.
- :func:`build_eval_context`          — assemble EvalContext from ingredients.
"""
from __future__ import annotations

import datetime
from zoneinfo import ZoneInfo

from chronos.enums import BatteryState, DayState, EvaluationDecision
from chronos.models.wake import TelemetryEvent, WakeEvaluation
from chronos.wake.rules import WakeRules
from chronos.wake.scoring import EvalContext, PreviousTick
from chronos.wake.signals import Signals
from chronos.wake.window import local_date_for, window_for


def make_previous_tick_from_row(
    we: WakeEvaluation,
    te: TelemetryEvent,
) -> PreviousTick:
    """Build PreviousTick from a (WakeEvaluation, TelemetryEvent) pair."""
    try:
        dt = datetime.datetime.fromisoformat(te.device_ts)
        if dt.tzinfo is None:
            dt = dt.replace(tzinfo=datetime.UTC)
    except ValueError:
        dt = datetime.datetime.now(datetime.UTC)
    return PreviousTick(
        device_ts=dt,
        local_date=datetime.date.fromisoformat(te.local_date),
        battery_state=BatteryState(te.battery_state),
        is_unlocked=bool(te.is_unlocked),
        score=we.score,
        decision=EvaluationDecision(we.decision),
        consecutive_high=we.consecutive_high,
    )


def build_eval_context(
    signals: Signals,
    rules: WakeRules,
    rule_version_number: int,
    previous: PreviousTick | None,
    ticks_received_today: int,
    day_state: DayState,
) -> EvalContext:
    """Assemble EvalContext from ingredients (no I/O)."""
    tz_obj = ZoneInfo(signals.tz)
    window_cfg = rules.window.to_window_config()
    local_date = local_date_for(signals.device_ts, tz_obj, window_cfg.day_boundary)
    window = window_for(local_date, tz_obj, window_cfg)
    return EvalContext(
        window=window,
        day_state=day_state,
        rule_version=rule_version_number,
        previous=previous,
        ticks_received_today=ticks_received_today,
    )
```

```python
"""Unicode sparkline for wake-score timelines (T1.8)."""
from __future__ import annotations

_BLOCKS = "▁▂▃▄▅▆▇█"
_N = len(_BLOCKS)  # 8

def sparkline(scores: list[int], width: int = 30) -> str:
    """Return a unicode sparkline on a fixed 0–100 scale.

    Each score in [0,100] maps to one of 8 block characters (▁…█).
    The output is exactly min(len(scores), width) characters.
    An empty list returns an empty string.

    Args:
        scores: List of integer scores in [0, 100].
        width:  Maximum number of characters to output (right-truncates).

    Returns:
        Unicode sparkline string.
    """
    if not scores:
        return ""
    visible = scores[:width]
    def _char(s: int) -> str:
        idx = min(int(s * _N / 101), _N - 1)
        return _BLOCKS[idx]
    return "".join(_char(s) for s in visible)
```

```python
"""GET /v1/report/{local_date} — serve the nightly Markdown report (T1.8)."""
from __future__ import annotations

import datetime
from pathlib import Path

from fastapi import APIRouter, Depends
from fastapi.responses import PlainTextResponse
from sqlmodel import Session, select

from chronos.auth import require_device
from chronos.config import get_settings
from chronos.db import get_session_dep
from chronos.errors import ProblemException
from chronos.models.devices import Device
from chronos.models.wake import Day
from chronos.report.builder import build_day_report

router = APIRouter(prefix="/report", tags=["report"])


@router.get("/{local_date_str}", response_class=PlainTextResponse)
def get_report(
    local_date_str: str,
    device: Device = Depends(require_device),
    session: Session = Depends(get_session_dep),
) -> str:
    """Return the Markdown report for a local date.

    Serves the file from `settings.reports_dir` if it exists; otherwise builds
    on-the-fly from the DB (no caching).

    Returns:
        200 text/markdown content.
        404 not_found if no day row exists for this device + date.
        422 if date format invalid.
    """
    # Validate date format.
    try:
        local_date = datetime.date.fromisoformat(local_date_str)
    except ValueError as exc:
        raise ProblemException(
            status_code=422,
            code="validation",
            title="Unprocessable Entity",
            detail=f"Invalid local_date {local_date_str!r}: must be YYYY-MM-DD.",
        ) from exc

    # 404 if no day row.
    assert device.id is not None
    day = session.exec(  # type: ignore[call-overload]
        select(Day).where(Day.local_date == local_date_str, Day.device_id == device.id)
    ).first()
    if day is None:
        raise ProblemException(
            status_code=404,
            code="not_found",
            title="Not Found",
            detail=f"No day row for local_date={local_date_str!r}.",
        )

    settings = get_settings()
    report_file = Path(settings.reports_dir) / f"{local_date_str}.md"
    if report_file.exists():
        return report_file.read_text(encoding="utf-8")

    now = datetime.datetime.now(tz=datetime.UTC)
    return build_day_report(session, device.id, local_date, now)
```

**Change — new `run_reports` method on `Scheduler`:**
```python
async def run_reports(self, now: datetime.datetime) -> None:
    """After the day boundary + 15 min grace, write previous day's report once.

    Called from run_forever after every run_due cycle.
    Idempotent: skips if file already exists.
    """
    if self._settings.reports_dir is None:
        return

    with self._session_factory() as session:
        devices = list(session.exec(select(Device).where(Device.status == "active")).all())
        for device in devices:
            try:
                await self._write_device_report(session, device, now)
            except Exception:
                log.exception("scheduler_report_error", device_id=device.id)
        session.commit()

async def _write_device_report(
    self, session: Session, device: Device, now: datetime.datetime
) -> None:
    """Write previous day's report if boundary passed + 15 min."""
    from zoneinfo import ZoneInfo
    from chronos.report.builder import build_day_report, write_day_report

    rules, _ = get_rules_cache().get_effective(session)
    window_cfg = rules.window.to_window_config()
    tz_obj = ZoneInfo(device.tz)
    # "Today" in device-local time — the previous day is what we report.
    today_local = local_date_for(now, tz_obj, window_cfg.day_boundary)
    prev_local = today_local - datetime.timedelta(days=1)
    prev_local_str = prev_local.isoformat()

    # Check if past boundary + 15 min grace.
    boundary_h, boundary_m = window_cfg.day_boundary
    boundary_local = datetime.datetime(
        today_local.year, today_local.month, today_local.day,
        boundary_h, boundary_m, tzinfo=tz_obj
    )
    grace = datetime.timedelta(minutes=15)
    if now < boundary_local.astimezone(datetime.UTC) + grace:
        return  # not yet time

    # Idempotency: skip if file exists.
    report_file = Path(self._settings.reports_dir) / f"{prev_local_str}.md"
    if report_file.exists():
        return

    # Require a day row; skip if none (device may be new).
    day = session.exec(  # type: ignore[call-overload]
        select(Day).where(
            Day.local_date == prev_local_str,
            Day.device_id == device.id,
        )
    ).first()
    if day is None:
        return

    assert device.id is not None
    content = build_day_report(session, device.id, prev_local, now)
    write_day_report(content, prev_local, Path(self._settings.reports_dir))
    log.info("scheduler_report_written", local_date=prev_local_str, device_id=device.id)
```

Wire into `run_forever` after `run_due`:


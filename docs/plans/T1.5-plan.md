# T1.5 Plan: Scoring engine `wake/scoring.py`

## 1. Summary

Adds the pure `evaluate(signals, rules, now, ctx) -> Evaluation` function to `services/api`,
completing the heart of the wake engine.  After this task:

- `wake/signals.py` defines the validated `Signals` pydantic model (every phone field, aware
  `device_ts`, bounds, enums, `extra="forbid"`) and the updated `SignalSpec` with `needs_pedometer`.
- `wake/scoring.py` defines all frozen pydantic types (`PreviousTick`, `EvalContext`,
  `DerivedFacts`, `RuleBreakdown`, `PenaltyBreakdown`, `Evaluation`) and implements `evaluate`.
- `Thresholds` in `rules.py` gains `confirm_max_gap_min: int = 12` (bounds [2, 60]).
- Golden fixtures cover 9 required mornings + `worked_example.json`; Hypothesis properties hold;
  `just check` and `just security` pass with ≥ 90 % coverage on `chronos.wake`.

## 2. Design

**Pure function**: `evaluate` takes only immutable inputs and returns a new `Evaluation` struct.
No I/O, no DB, no clock reads, no side effects; `now` is injected by the caller.

**Window gate first**: outside window → score 0, `outside_window` decision, empty breakdown, no
rules run.  Every other decision is subordinate.

**Decision precedence** (Owner Answer 5): `outside_window` → `already_confirmed` →
`ignored_dedupe` → `confirm` → `high` / `low`.

**Pedometer reweighting** (Owner Answer 17): when `pedometer_auth ∈ {denied, restricted,
not_determined}`, rules with `SignalSpec.needs_pedometer=True` are skipped with a note;
surviving rules in `reweight_without_pedometer` have **both** cap and effective points set to
the reweight value.  Bool/enum rules: `pts = reweight_value`.  Rules with `bonus_consecutive`:
`base_pts = reweight_value − bonus.points`; bonus takes pts to `reweight_value`.
Validator requires `reweight_value > bonus.points` (loc `reweight_without_pedometer.<rule>`).
Result: unlocked(35) + charger(25) + foreground(40) = 100; first tick with all three = 90 ≥ strong 85 → confirm.

**Derived facts inside evaluate**: `charger_disconnected`, `consecutive_unlocked_ticks`,
`minutes_since_window_start`, `ticks_received_today` — all computed from `ctx.previous` and
signals; never passed in externally.  Emitted in `Evaluation.derived` (not in the breakdown list).

**Rejected alternatives**:
- `Signals` in `wake/types.py` — owner said keep it in `wake/signals.py`.
- `confirm_max_gap_min` hardcoded — owner said add to `Thresholds` schema (Answer 4).
- Derived facts in breakdown list — owner said emit under `Evaluation.derived` (Answer 3).

**Files**: `wake/scoring.py` (new)

**Complete public interface**:

```python
# ── Supporting types ──────────────────────────────────────────────────────────

class PreviousTick(BaseModel):
    """Snapshot of the last evaluated tick (same local_date, in order)."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    device_ts: datetime          # tz-aware
    local_date: date
    battery_state: BatteryState
    is_unlocked: bool
    score: int                   # 0–100
    decision: EvaluationDecision
    consecutive_high: int

class EvalContext(BaseModel):
    """Server-side context passed into evaluate()."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    window: Window
    day_state: DayState
    rule_version: int
    previous: PreviousTick | None = None
    ticks_received_today: int = 0

class DerivedFacts(BaseModel):
    """Server-derived facts computed inside evaluate(); emitted for debugging."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    charger_disconnected: bool
    consecutive_unlocked_ticks: int     # 0, 1, or ≥ 2
    minutes_since_window_start: int
    ticks_received_today: int
    pedometer_unavailable: bool

class RuleBreakdown(BaseModel):
    """Per-rule contribution to the score."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    rule_id: str
    input: int | float | bool | str
    points: int
    cap: int
    note: str | None = None

class PenaltyBreakdown(BaseModel):
    """Per-penalty contribution."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    rule_id: str        # "penalty:<id>"
    points: int         # ≤ 0
    note: str | None = None

class ThresholdsEcho(BaseModel):
    """Echo of active thresholds for the API response."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    confirm: int
    strong: int
    confirm_max_gap_min: int

class Evaluation(BaseModel):
    """Complete scoring result returned by evaluate()."""
    model_config = ConfigDict(frozen=True, extra="forbid")
    gate: EvaluationGate
    score: int                    # 0–100
    decision: EvaluationDecision
    confirm_reason: Literal["strong", "consecutive", "both"] | None = None
    consecutive_high: int
    thresholds: ThresholdsEcho
    rule_version: int
    breakdown: tuple[RuleBreakdown, ...]   # rules in YAML order
    penalties: tuple[PenaltyBreakdown, ...>
    derived: DerivedFacts
    notes: tuple[str, ...] = ()


def evaluate(
    signals: Signals,
    rules: WakeRules,
    now: datetime,
    ctx: EvalContext,
) -> Evaluation:
    """Score the signals and return a decision (pure — no I/O).

    Algorithm (in order):
    1. Parse device_ts tz, compute local_date from signals.tz.
    2. Validate previous: different local_date or out-of-order → treat as None.
    3. Gate check: outside window → score 0, outside_window decision.
    4. Derive: charger_disconnected, consecutive_unlocked_ticks,
       minutes_since_window_start, pedometer_unavailable.
    5. Dedupe check: gap < dedupe_min * 60 s → mark deduped.
    6. Evaluate rules in YAML order; apply reweighting caps; bonus_consecutive.
    7. Evaluate penalties (AND-ed when conditions).
    8. Clamp score to [0, 100].
    9. Compute consecutive_high (deduped ticks do not advance).
    10. Determine decision and confirm_reason per precedence:
        outside_window → already_confirmed → ignored_dedupe → confirm/high/low.
    """
```

**Algorithm details** (exact logic, reviewable):

*Previous validation*:
```python
prev = ctx.previous
notes: list[str] = []
if prev is not None:
    if prev.local_date != local_date:
        notes.append(f"previous from {prev.local_date}, treating as None")
        prev = None
    elif prev.device_ts >= signals.device_ts:
        notes.append(f"out-of-order previous device_ts, treating as None")
        prev = None
```

*Gate check*:
```python
in_window = is_in_window(signals.device_ts, ctx.window)
gate = EvaluationGate.open if in_window else EvaluationGate.closed
if gate == EvaluationGate.closed:
    return Evaluation(gate=closed, score=0, decision=outside_window, consecutive_high=0, ...)
```

*Derived facts*:
```python
charger_disconnected = (
    prev is not None
    and prev.battery_state in {BatteryState.charging, BatteryState.full}
    and signals.battery_state == BatteryState.unplugged
)
consecutive_unlocked_ticks = (
    0 if not signals.is_unlocked else
    (2 if prev is not None and prev.is_unlocked else 1)
)
minutes_since_window_start = max(0, int(
    (signals.device_ts - ctx.window.start_utc).total_seconds() / 60
))
pedometer_unavailable = signals.pedometer_auth in {
    PedometerAuth.denied, PedometerAuth.restricted, PedometerAuth.not_determined
}
```

*Signal value lookup* (dict keyed by signal name):
```python
signal_values: dict[str, int | float | bool | str] = {
    "steps_10m": signals.steps_10m,
    "steps_since_window": signals.steps_since_window,
    "walking_sec_10m": signals.walking_sec_10m,
    "walking_conf": signals.walking_conf.value,
    "stationary_sec_10m": signals.stationary_sec_10m,
    "is_unlocked": signals.is_unlocked,
    "battery_state": signals.battery_state.value,
    "battery_level": signals.battery_level if signals.battery_level is not None else 0.0,
    "app_state": signals.app_state.value,
    "low_power_mode": signals.low_power_mode,
    "pedometer_auth": signals.pedometer_auth.value,
    "wake_source": signals.wake_source.value,
    "seq": signals.seq,
    # derived
    "charger_disconnected": charger_disconnected,
    "consecutive_unlocked_ticks": consecutive_unlocked_ticks,
    "minutes_since_window_start": minutes_since_window_start,
    "ticks_received_today": ctx.ticks_received_today,
}
```

*Rule evaluation* (for each rule in YAML order):
```python
spec = SIGNALS[rule.signal]
if pedometer_unavailable and spec.needs_pedometer:
    # skip: 0 pts, note "pedometer unavailable"
    continue

# requires check (AND logic)
for req_sig, req_vals in (rule.requires or {}).items():
    val = str(signal_values[req_sig])
    if val not in [str(v) for v in req_vals]:
        # 0 pts, note "requires ... got ..."
        break

# points: first satisfied threshold row
sig_val = signal_values[rule.signal]
pts = 0
for threshold, award in rule.points:
    if spec.kind == SignalKind.numeric:
        if isinstance(sig_val, (int, float)) and sig_val >= threshold:
            pts = int(award); break
    else:  # bool or enum
        if str(sig_val).lower() == str(threshold).lower():
            pts = int(award); break

# effective cap: reweighted if pedometer unavailable
effective_cap = (
    rules.reweight_without_pedometer[rule.id]
    if pedometer_unavailable and rule.id in rules.reweight_without_pedometer
    else rule.cap
)

# bonus_consecutive: only for unlocked rule with both ticks unlocked and gap ≤ max
bonus_note: str | None = None
if rule.bonus_consecutive and not deduped and pts > 0:
    if prev is not None and prev.is_unlocked and signals.is_unlocked:
        gap_min = (signals.device_ts - prev.device_ts).total_seconds() / 60
        if gap_min <= rules.thresholds.confirm_max_gap_min:
            bonus = rule.bonus_consecutive.points
            pts = min(pts + bonus, effective_cap)
            bonus_note = f"consecutive bonus +{bonus}"
elif pts > 0:
    pts = min(pts, effective_cap)
else:
    pts = min(pts, effective_cap)  # still cap (covers reweight = 0)
```

*Consecutive_high computation*:
```python
if deduped:
    consecutive_high = prev.consecutive_high if prev is not None else 0
elif score >= rules.thresholds.confirm:
    gap_ok = (
        prev is not None
        and (signals.device_ts - prev.device_ts).total_seconds() / 60
            <= rules.thresholds.confirm_max_gap_min
    )
    if prev is not None and prev.consecutive_high >= 1 and gap_ok:
        consecutive_high = prev.consecutive_high + 1
    else:
        consecutive_high = 1
else:
    consecutive_high = 0
```

*Decision + confirm_reason*:
```python
already_conf = ctx.day_state in {DayState.confirmed, DayState.delivered}
if gate == EvaluationGate.closed:
    decision, confirm_reason = EvaluationDecision.outside_window, None
elif already_conf:
    decision, confirm_reason = EvaluationDecision.already_confirmed, None
elif deduped:
    decision, confirm_reason = EvaluationDecision.ignored_dedupe, None
else:
    strong = score >= rules.thresholds.strong
    consec = consecutive_high >= 2
    if strong or consec:
        decision = EvaluationDecision.confirm
        if strong and consec: confirm_reason = "both"
        elif strong:          confirm_reason = "strong"
        else:                 confirm_reason = "consecutive"
    elif score >= rules.thresholds.confirm:
        decision, confirm_reason = EvaluationDecision.high, None
    else:
        decision, confirm_reason = EvaluationDecision.low, None
```

```python
@pytest.mark.parametrize("fixture_path", FIXTURE_DIR.glob("*.json"))
def test_morning(fixture_path):
    data = json.loads(fixture_path.read_text())
    rules = load_yaml(RULES_PATH)
    tz = ZoneInfo(data["tz"])
    window_cfg = rules.window.to_window_config()

    prev: PreviousTick | None = None
    ticks_today = 0
    confirmed_at_idx: int | None = None

    for i, event in enumerate(data["events"]):
        signals = Signals.model_validate({**event, "device_ts": event["device_ts"]})
        device_ts = signals.device_ts
        local_date = local_date_for(device_ts, tz, window_cfg.day_boundary)
        window = window_for(local_date, tz, window_cfg)

        # Determine day_state
        day_state = DayState.monitoring if confirmed_at_idx is None else DayState.confirmed

        ctx = EvalContext(
            window=window,
            day_state=day_state,
            rule_version=1,
            previous=prev,
            ticks_received_today=ticks_today,
        )

        now = device_ts  # use device_ts as "now" for fixture replay
        evaluation = evaluate(signals, rules, now, ctx)

        exp = event["expect"]
        assert evaluation.gate.value == exp["gate"], f"event {i}: gate"
        assert evaluation.score == exp["score"], f"event {i}: score"
        assert evaluation.decision.value == exp["decision"], f"event {i}: decision"
        assert evaluation.consecutive_high == exp["consecutive_high"], f"event {i}: consecutive_high"
        if "confirm_reason" in exp:
            assert evaluation.confirm_reason == exp.get("confirm_reason"), f"event {i}: confirm_reason"

        if evaluation.decision == EvaluationDecision.confirm and confirmed_at_idx is None:
            confirmed_at_idx = i

        # Thread context for next event
        prev = PreviousTick(
            device_ts=device_ts,
            local_date=local_date,
            battery_state=signals.battery_state,
            is_unlocked=signals.is_unlocked,
            score=evaluation.score,
            decision=evaluation.decision,
            consecutive_high=evaluation.consecutive_high,
        )
        ticks_today += 1

    # Check confirm timing
    if "expect_day" in data:
        exp_day = data["expect_day"]
        if "confirmed_at_event_index" in exp_day:
            assert confirmed_at_idx == exp_day["confirmed_at_event_index"]
        elif exp_day.get("confirmed_at") is None:
            assert confirmed_at_idx is None
```

### Step 6 — Hypothesis properties `tests/wake/test_scoring_properties.py`

**Properties**:
1. `test_score_in_range` — score always ∈ [0, 100] for any valid signals.
2. `test_outside_window_always_zero` — if device_ts is before window.start_utc, score=0 and decision=outside_window.

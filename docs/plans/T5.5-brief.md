## What `chronos simulate-morning` does

It runs the **real** scheduler, wake engine, pipeline worker and delivery on a **simulated clock**, against an **isolated** temp database and data dir (the live ones are never touched). A fake phone answers every silent tick: in bed (charging, locked, still) before `--wake`, then up and walking. It exits 0 only if every check passes.

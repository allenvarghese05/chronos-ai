# T2.3 implementation plan

## Summary

Add a bounded manual telemetry sampler and durable, identity-partitioned SQLite outbox.
Publish the existing Signals request contract, including approved optional tick_seq.
Events retain seq, body and original timestamp through retries and process restart.
No background registration, server scoring changes, or new sensor sources.

## Design

Pure builder accepts one captured instant/timezone, native state, permission and bounded readings.
Sensor promises run in parallel with 5-second individual deadlines; late values are ignored.
Session leases capture the existing generation and identity without a second credential store.
SQLite synchronous short transactions allocate sequence and enqueue atomically; no network await
inside transactions. At most256queued records globally and32KiB per body, at most2hours retention.
A single flush owner sends FIFO with an8second abortable budget, persisted retryAt and exponential
backoff capped60seconds plus bounded server Retry-After. Confirmed401/403 invalidate centrally.
Drop terminal4xx except408/429; server422clock_skew drops original event, never rewrites time.
Reject stale/future local queue metadata to avoid indefinite retention after clock changes.
Prefer supplied trusted context matching timezone/local date with valid offset windowStart;
without it use zero window steps and a local diagnostic. No local rules/DST reconstruction.

Rejected: token in SQLite (D34); unpartitioned sequence (identity leak); Promise.race-only network
budget (late effects); holding async transaction across fetch (locks); guessed window (owner2).

## Steps and public interfaces

1. **Contract repair**. Signals adds `tick_seq: int | None = Field(default=None, ge=0)`;
   service stores `signals.tick_seq`. create_app wraps standard OpenAPI export once, merging
   `Signals.model_json_schema(ref_template='#/components/schemas/{model}')` plus its $defs into
   components, declaring required application/json body `$ref: #/components/schemas/Signals`.
   Route/raw-size/auth/skew/dedup code stays unchanged. Verify telemetry/openapi pytest tests,
   just gen-types and staleness. Tests omitted/null/0 accepted, negative rejected, stored value,
   requiredbody/forbiddenextra/64KiB unchanged.
2. **Dependencies, builder and sampling**. Install pins below. Export generated `Telemetry` and
   `TelemetryResult`. `buildTelemetry(input: SampleInput, seq:number): Telemetry` is pure;
   `sample(sensors, source, now, tz, appVersion, context?): Promise<Sample>` captures now/tz
   before awaits. `Sample={input,diagnostics:string[]}`. Native missing iosVersion0.0 skips.
   No native permission request. Step normalization exactly
   `finite? min(5000,max(0,floor(value))):0`; durations min600/max0/floor(walking+running),
   stationary same. Unknown/nonfinite battery becomesnull; finite battery clamps0..1.
   Context validates timezone equality, captured local date equality via Intl, explicit ISO
   offset, windowStart<=now and age<=24hours; absent/invalid context yieldszero+diagnostic.
   Authorization is native actual enum, timeout/rejection falls backnot_determined withdiagnostic.
   Query errors yieldzero/low but state remains actual. Verify fixed-clock Jest for schema
   extras, clamp/running/battery/auth/stub, DST/travel/context, hanging/late queries; both tsc.
3. **Transport/session seam**. `createApi.telemetry(body:Telemetry,
   options:{signal:AbortSignal; timeoutMs:number}):Promise<TelemetryResult>` joins fixed endpoint,
   bearer only approved paths. Remaining deadline links external abort to internal controller;
   body-read abort cancels reader and rejects promptly. Error parser reads <=32KiB and accepts
   only code `clock_skew|validation|rate_limited|revoked|unauthorized`, optional valid server_time;
   UI always fixed diagnostics. Session `lease(): SessionLease|null` returns
   `{identity:string,current():boolean,run<T>(operation:(api:Api)=>Promise<T>):Promise<T>}`.
   Identity canonicalapiBase+'|'+deviceId; lease current requires same generation/authenticated.
   run checks before/after and invokes existing central auth clearing for matching401/403 only.
   Verify client hanging fetch/body abort, redirect/auth/origin, malformed/oversized problems;
   lease old401/newpair race, stale completion, no Keychain policy change.
4. **Durable store**. `createOutbox(db:Database):Outbox` initializes schema idempotently.
   `enqueue(identity,now,build:(seq)=>Telemetry):Row`, `head(identity):Row|null`,
   `ack(identity,seq):void`, `defer(identity,seq,retryAt,attempts):void`,
   `prune(now):number`, `count(identity):number`, `retire(identity):void` are synchronous.
   All SQL data parameters bound; fixed schema SQL only uses exec. Schema:

   ```sql
   CREATE TABLE IF NOT EXISTS telemetry_counters(identity TEXT PRIMARY KEY,next_seq INTEGER NOT NULL);
   CREATE TABLE IF NOT EXISTS telemetry_outbox(identity TEXT NOT NULL,seq INTEGER NOT NULL,
     body TEXT NOT NULL,created_ms INTEGER NOT NULL,retry_ms INTEGER NOT NULL DEFAULT 0,
     attempts INTEGER NOT NULL DEFAULT 0,PRIMARY KEY(identity,seq));
   ```

   enqueue uses withTransactionSync: pruneexpired/future rows, count global<256, readnext(default1),
   require safe seq<MAX_SAFE_INTEGER, build/serialize/check<=32768, insert row and UPSERTcounter
   nextseq+1 atomically. Rollback leaves no allocated seq on failure. Counters survive rowdrops.
   prune condition `created_ms < now-7200000 OR created_ms > now` (exact2h retained).
   FIFO `WHERE identity=? ORDER BY seq LIMIT1`; ACK/DEFER both identity+seq bound.
   JSONparse/corruption is surfaced and terminally removed under matching row, never logged.
   Verify SQL rollback/reopen/atomicconcurrency/maxsafe/cap/expiry/future/partition tests and
   actual native SQLite runtime acceptance, not only mocks.
5. **Controller and UI**. `createTelemetryController({session,sample,outbox,now})` returns
   `sampleAndSend(source,context?):Promise<void>`, `flush():Promise<void>`, `status()` and
   `subscribe(listener)`. One sample owner + one flush owner; snapshot stays immutable.
   sample obtains lease, awaits<=5s sample, checkslease, syncenqueue, thenflush<=8s.
   flush captures lease, prune, FIFO loop whiletime remains, honors persistedretryAt;
   telemetry call uses remainingbudget, AbortController. After eachawait checkslease/deadline
   before ACK/status; matching401/403 centrallyclears andretiresoldpartition; transient keepshead,
   updatesattempt/retryAt `now+max(min(60000,1000*2^min(attempt,6)),serverRetryAfter*1000)`.
   Terminal4xx excluding408/429 ACKdrop thencontinue. Late timeout cannot mutateafterreturn.
   Status boundedcount/seq/outcome/diagnostics only, no rawpayload/token. Lazy singletonnative
   composition opens SQLite once. Minimal home buttons samplemanual/retry/status only;
   no auto sample/flush or wake handlers. Verify FIFO lostACK/backoff/auth/newidentity races,
   totalbudget, corruption/terminalcontinuation and protectedhome.
6. **Full/native/real acceptance**. just check + just security + nativepodinstall and normallysigned

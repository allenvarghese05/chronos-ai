# T0.7 Plan: Shared schema tooling — `just gen-types`

## 1. Summary

Adds `chronos openapi export [--out PATH]` CLI command that deterministically serialises the
FastAPI OpenAPI schema (sorted keys, indent=2, trailing newline, version from VERSION).  Wires
`HTTPBearer(auto_error=False)` through `require_device` so the security scheme is native, adds a
hand-declared `Problem` component plus `responses=` for 401/403/422/429 on authenticated routers,
and stable `<tag>_<route-name>` operationIds via `generate_unique_id_function`.  `scripts/gen-types.sh`
calls the CLI then runs `openapi-typescript` to produce `apps/mobile/src/api/schema.d.ts`.  Both
generated files are committed.  CI catches staleness in the `api` job (openapi diff) and the
`mobile` job (schema.d.ts diff).

## 2. Design

**OpenAPI export as a CLI command** — keeps the export logic in Python, no separate tooling or
network call; `sort_keys=True` + `indent=2` + trailing newline is sufficient for determinism on
macOS and Linux; version is already read from VERSION by `chronos/__init__.py` and used in the
`FastAPI()` constructor.

**Native HTTPBearer** — FastAPI registers the security scheme in OpenAPI automatically when
`HTTPBearer` appears in `Depends()`.  Using `auto_error=False` preserves our ProblemException 401
behaviour.  Alternative (manual patching after `app.openapi()`) rejected: brittle, not visible to
FastAPI's introspection.

**Problem Pydantic model** — lives in `errors.py`, used as `responses=` model so FastAPI generates
a real schema component rather than an inline object.  Alternative (inline dict in the export
patch) rejected per owner answer 4.

**generate_unique_id_function `<tag>_<route-name>`** — stable across router file reorganisations;
matches the `<tag>_<route-name>` pattern from owner answer 7.

**Renderer hook is commented-out** — T3.4 will fill it in; T0.7 does not create a
`packages/renderer/src/schema.json` stub (the old CI step that diffed that file is replaced by the
direct diff approach).

**CI staleness split** — api job diffs `openapi.json` (no Node needed); mobile job diffs
`schema.d.ts` (already has pnpm/Node).

### Step 2 — `chronos openapi export` CLI command

**Files:** `services/api/src/chronos/cli.py`

**Full interface:**
```python
openapi_app = typer.Typer(
    name="openapi",
    help="OpenAPI schema commands.",
    no_args_is_help=True,
)
app.add_typer(openapi_app, name="openapi")

@openapi_app.command("export")
def openapi_export(
    out: Path = typer.Option(
        Path(__file__).parents[2] / "openapi.json",
        "--out",
        help="Output path (default: services/api/openapi.json relative to this file).",
    ),
) -> None:
    """Export the OpenAPI 3.1 schema to a deterministic JSON file.

    The output is JSON with sorted keys, indent=2 and a trailing newline,
    ensuring byte-identical output across platforms and repeated runs.
    info.version comes from the repo-root VERSION file via chronos.__version__.
    """
    import json

    from chronos.config import Settings
    from chronos.main import create_app

    # Use test-safe settings (no real DB needed; skip rules init).
    settings = Settings(
        database_url="sqlite:///",
        skip_rules_init=True,
        scheduler_enabled=False,
    )
    fastapi_app = create_app(settings)
    schema: dict[str, object] = fastapi_app.openapi()  # type: ignore[assignment]

    out.parent.mkdir(parents=True, exist_ok=True)
    content = json.dumps(schema, sort_keys=True, indent=2) + "\n"
    out.write_text(content, encoding="utf-8")
    typer.echo(f"✓ OpenAPI schema written to {out} ({len(content)} bytes)")
```

```bash
#!/usr/bin/env bash
# gen-types.sh — T0.7 shared schema tooling
# Exports the FastAPI OpenAPI schema, then generates TypeScript types for mobile.
# The renderer zod step (T3.4) is guarded below; uncomment when ReelProps model exists.
set -euo pipefail

REPO_ROOT="$(cd "$(dirname "$0")/.." && pwd)"

# ── Step 1: export OpenAPI schema ─────────────────────────────────────────────
echo "→ Exporting OpenAPI schema …"
(cd "$REPO_ROOT/services/api" && \
  uv run --locked chronos openapi export \
    --out "$REPO_ROOT/services/api/openapi.json")
echo "✓ services/api/openapi.json updated"

# ── Step 2: generate TypeScript types for mobile ─────────────────────────────
if [ -f "$REPO_ROOT/apps/mobile/package.json" ]; then
  echo "→ Generating mobile TypeScript types …"
  mkdir -p "$REPO_ROOT/apps/mobile/src/api"
  (cd "$REPO_ROOT/apps/mobile" && \
    pnpm exec openapi-typescript \
      "$REPO_ROOT/services/api/openapi.json" \
      -o src/api/schema.d.ts)
  echo "✓ apps/mobile/src/api/schema.d.ts updated"
```

# T1.2 Plan: Pairing and device auth

## 1. Summary

Implements the full device-pairing lifecycle: `chronos pair-code` generates an 8-char code
(XXXX-XXXX display, no-ambiguity alphabet, `segno` QR in terminal), `POST /v1/pair` validates
it (10-min expiry, 5-attempt burn, one-active-device conflict guard) and returns a 256-bit bearer
token. `GET/PATCH/DELETE /v1/device/me` lets the paired phone manage itself. Every `/v1` endpoint
except `POST /v1/pair` requires a valid, non-revoked bearer token (SHA-256 hashed at rest,
constant-time compare, 401 unknown / 403 revoked). A hand-rolled in-memory token-bucket rate
limiter (injectable clock for tests) applies 5/min on pairing and 120/min everywhere else.

## 2. Design

**Approach**: pure stdlib crypto (no external auth library), hand-rolled token bucket (no slowapi
as per owner answer 3 and docs/09-security.md §2), `segno` for QR (owner answer 1, pure Python).

Auth flow: `generate_pairing_code()` → 8 chars from `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (no
0/O/1/I), `sha256(normalise(code))` stored; `new_token()` → `secrets.token_urlsafe(32)` (43
chars), `sha256(token)` stored. `require_device` dep: extract Bearer → hash → lookup →
401/403/Device. `last_seen_at` bumped at most once per 60 s.

**Rejected alternatives**:
- `slowapi`: external dep, not needed for single-user LAN (owner answer 3).
- `qrcode`: owner chose `segno` (lighter, pure Python, owner answer 1).
- Auto-revoke old device on re-pair: owner requires explicit revoke first → 409 (owner answer 6).
- `X-Forwarded-For` trust: ignored; LAN-direct; keyed by `request.client.host` only.
- Separate 410 status for `pairing_invalid` burned code: 400 is correct (code is not gone, it is
  invalid; only expiry is 410).

### Step 5 — `ratelimit.py`: in-memory token bucket

**Files**: `services/api/src/chronos/ratelimit.py`

**Interface** (complete):
```python
"""In-memory token-bucket rate limiter (docs/09-security.md §2, owner answer 3).

One bucket per (name, client IP) pair.  The clock is injectable so tests can
advance time without sleeping.  Limits come from Settings; the factory
``rate_limit(name, per_minute)`` returns a FastAPI dependency that raises
``ProblemException(429)`` with a ``Retry-After`` header on exhaustion.
"""
from __future__ import annotations
import threading
import time as _time
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import Annotated

from fastapi import Depends, Request

from chronos.errors import ProblemException


@dataclass
class _Bucket:
    tokens: float
    last_refill: float


class TokenBucket:
    """Thread-safe sliding-window token bucket.

    Args:
        per_minute: Maximum allowed requests per 60-second window.
        clock: Callable returning monotonic seconds.  Defaults to
               ``time.monotonic``.  Inject a fake in tests.
    """
    def __init__(self, per_minute: int, clock: Callable[[], float] | None = None) -> None:
        self._per_minute = per_minute
        self._rate = per_minute / 60.0  # tokens per second
        self._clock: Callable[[], float] = clock or _time.monotonic
        self._buckets: dict[str, _Bucket] = {}
        self._lock = threading.Lock()

    def check(self, key: str) -> tuple[bool, int]:
        """Consume one token for *key*.

        Returns:
            (allowed, retry_after_seconds): allowed is True when a token was
            consumed.  retry_after_seconds is 0 when allowed.
        """
        now = self._clock()
        with self._lock:
            if key not in self._buckets:
                self._buckets[key] = _Bucket(
                    tokens=float(self._per_minute) - 1.0, last_refill=now
                )
                return True, 0
            bucket = self._buckets[key]
            elapsed = now - bucket.last_refill
            bucket.tokens = min(float(self._per_minute), bucket.tokens + elapsed * self._rate)
            bucket.last_refill = now
            if bucket.tokens >= 1.0:
                bucket.tokens -= 1.0
                return True, 0
            retry_after = max(1, int((1.0 - bucket.tokens) / self._rate) + 1)
            return False, retry_after

    def reset(self) -> None:
        """Clear all buckets (tests only)."""
        with self._lock:
            self._buckets.clear()


# Module-level registry so each (name, per_minute) combination shares one bucket.
_registry: dict[str, TokenBucket] = {}
_registry_lock = threading.Lock()


def _get_or_create(name: str, per_minute: int, clock: Callable[[], float] | None) -> TokenBucket:
    key = f"{name}:{per_minute}"
    with _registry_lock:
        if key not in _registry:
            _registry[key] = TokenBucket(per_minute=per_minute, clock=clock)
        return _registry[key]


def reset_all() -> None:
    """Clear all registered buckets (call in test teardown)."""
    with _registry_lock:
        for b in _registry.values():
            b.reset()
        _registry.clear()


def rate_limit(
    name: str,
    per_minute: int,
    clock: Callable[[], float] | None = None,
) -> Callable[[Request], None]:
    """Return a FastAPI dependency that enforces a per-IP rate limit.

    Args:
        name:       Logical limiter name (e.g. ``"pairing"``).  Determines
                    which bucket the IP draws from.
        per_minute: Maximum requests per 60-second window.
        clock:      Injectable monotonic clock (``Callable[[], float]``).
                    Defaults to ``time.monotonic``.  Tests pass a fake here.

    Returns:
        A zero-argument callable suitable for ``Depends()``.

    Usage::

        router = APIRouter()
        _pairing_limit = rate_limit("pairing", per_minute=5)

        @router.post("/v1/pair")
        def pair(request: Request, _: None = Depends(_pairing_limit)):
            ...
    """
    bucket = _get_or_create(name, per_minute, clock)

    def _check(request: Request) -> None:
        ip: str = request.client.host if request.client else "unknown"
        allowed, retry_after = bucket.check(ip)
        if not allowed:
            raise ProblemException(
                status_code=429,
                code="rate_limited",
                title="Too Many Requests",
                detail=f"Rate limit exceeded. Retry after {retry_after} seconds.",
                headers={"Retry-After": str(retry_after)},
            )

    return _check
```

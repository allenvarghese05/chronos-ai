# T1.7 Plan: Scheduler + Silent Ticks + Expo Push Client

## 1. Summary

Adds the scheduler loop (hand-rolled asyncio task, 60 s tick), the `push_notifications` table
(migration 0002), the Expo push client stack (`PushClient` Protocol + `ExpoPushClient` + `FakePushClient`),
and the pure planner (`plan()` → list of Actions). The scheduler drives idle→monitoring at window
start, sends one silent tick per tick instant, applies monitoring→fallback at window end, and runs
a receipts-check every 15 min. The telemetry response gains a live `next_tick_in_sec`. Tests
simulate a full weekday (05:50→11:05 in 1-min steps) and all error scenarios.

## 2. Design

**Hand-rolled asyncio loop** (not APScheduler): no new dependency, deterministic with injectable
clock, single background asyncio.Task started/stopped in lifespan.

**Pure planner** `plan(now, device, day, window, sent_tick_seqs, last_rate_limited_at)` returns
`list[Action]` (StartMonitoring | SendTick | Fallback | Noop) with no I/O; enables exact minute-
by-minute simulation tests.

**PushClient Protocol** (structural subtyping): `ExpoPushClient` wraps httpx (already in deps),
`FakePushClient` for tests. Retry on 5xx/429 is inside `ExpoPushClient` (backoff inside client,
not in scheduler — simpler separation).

**`next_tick_in_sec`**: scheduler stores next tick instants in a module-level dict keyed by
`device_id`; telemetry endpoint reads it.

Rejected alternatives:
- APScheduler: extra dependency, harder test determinism.
- New `days.last_tick_seq` column: duplicates push_notifications, owner said derive from DB.
- PushClient retries outside client: makes scheduler stateful for retry; client is cleaner.

### Step 3 — Pure planner `plan()`

**Files touched:** `src/chronos/scheduler.py` (plan section only)

**Full signature and Action types:**

```python
import datetime
from dataclasses import dataclass
from typing import Union
from chronos.models.devices import Device
from chronos.models.wake import Day
from chronos.wake.window import Window

@dataclass(frozen=True)
class StartMonitoring:
    pass

@dataclass(frozen=True)
class SendTick:
    tick_seq: int
    instant: datetime.datetime   # UTC

@dataclass(frozen=True)
class Fallback:
    pass

@dataclass(frozen=True)
class Noop:
    reason: str

Action = Union[StartMonitoring, SendTick, Fallback, Noop]

def plan(
    now: datetime.datetime,           # UTC-aware
    device: Device,
    day: Day,
    window: Window,
    sent_tick_seqs: frozenset[int],   # tick_seqs already sent (from push_notifications)
    last_rate_limited_at: datetime.datetime | None,  # UTC of last MessageRateExceeded
) -> list[Action]:
    """Pure function — no I/O.

    Rules (in order):
    1. If day.state in (confirmed, fallback, delivered) → [Noop("already_terminal")]
    2. If now >= window.end_utc and day.state == monitoring → [Fallback()]
    3. If now < window.start_utc → [Noop("before_window")]
    4. If now >= window.start_utc and day.state == idle → [StartMonitoring()] (window start)
    5. If day.state == monitoring:
       a. Compute next due tick_seq: all instants in tick_instants(window) not in sent_tick_seqs
          and instant <= now.
       b. If rate-limited: skip instants at last_rate_limited_at; next is the following instant.
       c. Return [SendTick(seq, instant)] for the next due one (at most one per call).
    6. → [Noop("idle_before_window_start")]
    """
```

```python
from collections.abc import Callable
from sqlmodel import Session

class Scheduler:
    """Asyncio-based scheduler. Clock injectable for tests."""

    def __init__(
        self,
        *,
        session_factory: Callable[[], Session],
        push_client: PushClient,
        settings: Settings,
        clock: Callable[[], datetime.datetime] | None = None,  # default: utc_now
    ) -> None:
        # _next_tick_instants: dict[int, datetime.datetime]  — device_id → next tick UTC
        # _warned_no_token: dict[int, str]  — device_id → local_date (suppress log repeat)
        ...

    def get_next_tick_for(self, device_id: int) -> datetime.datetime | None:
        """Return next tick instant for device_id, or None if not monitoring."""
        ...

    async def run_due(self, now: datetime.datetime) -> None:
        """Check all active devices; apply due actions. Called every 60 s."""
        ...

    async def run_receipts(self, now: datetime.datetime) -> None:
        """Check receipts for tickets ≥ 15 min old without receipt_status."""
        ...

    async def run_forever(self, stop_event: asyncio.Event) -> None:
        """Main loop: run_due every 60 s, run_receipts every 15 min."""
        ...
```

**`run_due(now)` logic:**
1. Open session; query `Device` where `status=active`.
2. For each device:
   a. If `expo_push_token` is None: log warning once per day (suppress repeats via `_warned_no_token`); skip.
   b. Get effective rules; compute `local_date` and `window`.
   c. `get_or_create_day(session, device, local_date, device.tz, rules, now)`.
   d. Query `sent_tick_seqs = SELECT tick_seq FROM push_notifications WHERE device_id=? AND local_date=?`.
   e. Query `last_rate_limited_at` from push_notifications (most recent tick with error=MessageRateExceeded).
   f. Call `plan(now, device, day, window, frozenset(sent_tick_seqs), last_rate_limited_at)`.
   g. For each action in plan result:
      - `StartMonitoring`: call `_do_start_monitoring(session, device, day, now)`.
      - `SendTick(seq, instant)`: call `_do_send_tick(session, device, day, seq, instant, now)`.
      - `Fallback`: call `_do_fallback(session, device, day, now)`.
      - `Noop`: log at debug.
   h. Update `_next_tick_instants[device.id]` after sending.
3. Commit session.

**`_do_send_tick()` logic:**
1. Build `PushMessage(to=device.expo_push_token, data={type, local_date, tick_seq, window_start})`.
2. Call `push_client.send([message])` → `[ticket]`.
3. Build `payload_json` without token.
4. Insert `PushNotification(device_id, kind=tick, local_date, tick_seq=seq, payload_json, ticket_id, ticket_status, error, sent_at)`.
5. If ticket.message == "DeviceNotRegistered": clear `device.expo_push_token = None`; log once.
6. If ticket.message == "MessageRateExceeded": log warning; record error.
7. If ticket_status == "ok": increment `day.ticks_sent += 1`.
8. Update `_next_tick_instants[device.id]` = next instant after seq (from tick_instants).

**`_do_start_monitoring()` logic:**
- Insert `DayTransition(from_state=idle, to_state=monitoring, cause=scheduler_window_start)`.
- Set `day.state = monitoring`.

**`_do_fallback()` logic:**
- If `day.state != monitoring`: log "already terminal, skip"; return.
- Insert `DayTransition(from_state=monitoring, to_state=fallback, cause=scheduler_window_end)`.
- Set `day.state = fallback`, `day.fallback_used = 1`.
- Call `on_fallback(session, day)` (no-op hook).

**`run_receipts(now)` logic:**
1. Query `push_notifications WHERE receipt_status IS NULL AND sent_at < (now - 15 min) AND ticket_id IS NOT NULL AND ticket_status = 'ok'`.
2. Chunk ticket_ids ≤ 1000; call `push_client.get_receipts(ids)`.
3. Update each row: `receipt_status`, `receipt_checked_at = now`.
4. Commit.

**`run_forever(stop_event)` logic:**
```
last_receipts_check = now - 15 min (force first run)
while not stop_event.is_set():
    now = clock()
    await run_due(now)
    if (now - last_receipts_check) >= timedelta(minutes=15):
        await run_receipts(now)
        last_receipts_check = now
    try:
        await asyncio.wait_for(stop_event.wait(), timeout=60.0)
    except asyncio.TimeoutError:
        pass
```

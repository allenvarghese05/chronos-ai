# T3.3 — Normalise, dedupe, rank, select (plan)

Brief: `docs/plans/T3.3-brief.md` (owner gate: approve all). Branch `t3-3-normalise-rank-select`
(stacked on T3.2 / PR #43).

## 1. Summary

The pipeline is ParsedItems → `normalise` → `upsert_items` (`items` table) → candidate window
from the DB → `cluster` (union-find over shared dedupe-hash or near simhash) → `score` →
`select` (category minimums, then by score, under per-source quotas) → ordered
`list[SelectedStory]` in narrative order (ai, tech, world, india). No job, endpoint or CLI wiring
(T3.5). No new dependencies.

## 3. Key rules

- **`canonical_url`**:
  - http(s) only (else `None`);
  - lowercase scheme and host;
  - drop default ports and the fragment;
  - drop `utm_*`, `fbclid`, `gclid`, `ref`, `ref_src`, `mc_cid`, `mc_eid`, `at_medium`,
    `at_campaign`, `cmpid`;
  - sort the remaining query;
  - strip the trailing `/` (the root path becomes empty).
- **`dedupe_key`**: canonical URL, plus:
  - strip `www.` and `amp.` host prefixes;
  - drop a trailing `/amp` or `/amp/<digits>` path segment;
  - drop `amp` and `outputType=amp` query params.
- **`url_hash`** = sha256 hex of `dedupe_key`.
- **`simhash64`**:
  - tokens = `\w+` over NFKC-casefolded title;
  - blake2b-8 per token, ±1 per bit;
  - bit set where the sum is > 0;
  - no tokens gives 0.
- **Duplicate** if equal `url_hash`, or (both titles have ≥ 4 content tokens, word-set Jaccard
  ≥ 0.6, and |Δpublished| ≤ 36 h), per **ADR D35** (owner decision during implementation;
  simhash ≤ 6 failed the calibration set). `title_simhash` is still stored.
- **Primary** = max of `(weight, popularity, published_at, -item_id)`. `n_sources` counts the
  distinct source keys in the cluster.
- **Score** = `weight × recency × popularity × (1 + boost × (n_sources − 1))`, all taken from
  the primary.
  - Recency is linear from 1.0 at 0 h to 0.3 at `freshness_hours`, with age clamped ≥ 0.
  - A cluster is stale when its age > `freshness_hours`.
- **Select**:
  - The pool is the fresh clusters, plus the single best stale cluster of each category that
    has no fresh cluster.
  - Phase 1: for each category in narrative order, take the best clusters up to its minimum.
  - Phase 2: fill by score.
  - Both phases honour quotas (counted on the primary's source) and stop at `total_stories`.
  - Output is sorted by narrative category order, then score desc.
  - Ties break on `(score desc, published_at desc, item_id asc)`.
  - Unknown `category_min` keys are ignored.

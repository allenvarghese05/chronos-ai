## 2. Key rules

- **Word count:** `len(text.split())`, summed over every scene's voiceover. Valid range is 130–185
  for ≥ 3 stories. With fewer stories the range scales: minimum `max(40, 130 × n/6)`, maximum 185.
  The 6-story reel is the docs case, and 1–2 story days can't reach 130 honestly.
- **Story voiceover:** 25–45 words (prompt target; validator enforces 15–60 to stay
  retry-friendly).
- **Structure:** first scene is `cover`, last is `outro`, indices contiguous from 0. Story scenes
  map 1:1 to the candidates, in order, with `item_id` equal and `source_url == candidate.url`
  exactly. Cover and outro have no `item_id`/`source_url`.
- **`total_words`:** always recomputed by `validate_script`; the LLM value is overwritten.
- **Chain:**
  - Ollama gets up to 3 attempts, with validation errors appended. A connect error or 404 skips
    it at once.
  - Optional provider: up to 2 attempts.
  - Template last.
  - Each request's timeout is `min(provider timeout, remaining deadline − 5 s)`, from a deadline
    of 270 s (job timeout 300 s).

## 4. Implementation notes

- ADR D37 (owner, 2026-11-09): per-story calls plus a frame call; code assembles the script;
  failed pieces are patched from the template. Story voiceover 8–24 words for 6 stories.
- Real-model smoke (`@pytest.mark.ollama`): 7/7 pieces valid first try, 24 s, digest
  `sha256:845dbda0…` pinned in the justfile.
- `ReelProps` (Pydantic, `chronos/media/reel_props.py`) is exported by
  `chronos schema export-reel-props` to `packages/renderer/src/schema.generated.ts` (zod,
  in-repo generator) and `services/api/reel_props.schema.json`. `schema.ts` keeps the
  refinements and the discriminated union. A pytest test fails when the committed files are
  stale. `tone` is `calm | energetic` everywhere.
- `.env.example` could not be edited from the agent sandbox; the new variables are listed in the PR.

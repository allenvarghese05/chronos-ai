# T0.4b Plan: Prebuild + Simulator run; verify Swift hello()

## 1. Summary

Runs `expo prebuild --platform ios --clean` in `apps/mobile`, confirms the generated Xcode
workspace/scheme names and fixes `.github/workflows/ios-build.yml` if they mismatch. Adds a
`just mobile-sim` recipe (env-overridable simulator name, default "iPhone 16 Pro"). Builds,
installs and launches the dev-client on the iPhone 16 Pro iOS 18.6 simulator; proves the Swift
`hello()` string appears on screen (not the JS fallback). Commits a screenshot. Updates docs.

## 2. Design

- `expo run:ios --device "<name>"` accepts a simulator name string and boots it automatically;
  no UDID needed for the recipe.
- `CHRONOS_SIM` env var (default "iPhone 16 Pro") keeps the recipe flexible for other simulator
  sizes without editing the justfile.
- macOS-only guard mirrors `mobile-build` — prints "requires macOS, skipping" on Linux CI.
- Fallback string ("ChronosSensors unavailable") already differs from the Swift string
  ("Hello from ChronosSensors!"), so no source change is needed for the proof.
- Screenshot captured with `xcrun simctl io booted screenshot`; downscaled to ≤ 500 KB if needed.

Rejected alternatives:
- Using `expo start --dev-client` + separate `xcrun simctl install`: more steps, no real benefit.
- Pinning UDID in justfile: brittle across machine resets; name is stable.
- Adding `--no-build-cache` to xcodebuild: unnecessary complexity.

### Step 2 — add `just mobile-sim` recipe

**Files touched:** `justfile`

**Change:** Insert after the `mobile-build` recipe:

```just
# Boot (or reuse) the iOS Simulator named by CHRONOS_SIM (default "iPhone 16 Pro") and
# run the dev-client. macOS only. First run compiles Pods — allow several minutes.
mobile-sim:
    #!/usr/bin/env bash
    set -euo pipefail
    cd "{{justfile_directory()}}/apps/mobile" 2>/dev/null || { echo "apps/mobile not yet scaffolded, skipping mobile-sim"; exit 0; }
    [ "$(uname -s)" = "Darwin" ] || { echo "mobile-sim requires macOS, skipping"; exit 0; }
    sim="${CHRONOS_SIM:-iPhone 16 Pro}"
    pnpm exec expo run:ios --device "$sim"
```

**Tests:** `just --list` shows `mobile-sim`; `just --dry-run mobile-sim` exits 0 on macOS.

**Verify command:**
```bash
just --list | grep mobile-sim
```
Passing: line containing `mobile-sim` appears.

# T3.2 — SSRF-guarded HTTP client, sources.yaml loader and feed fetchers

## 1. Summary

- `chronos/http.py` — async `GuardedHttpClient` with injectable DNS resolver, manual redirect loop, pre-connect IP-range block (IPv4+IPv6), content-type allowlist, and streaming `max_bytes` abort.
- `config/sources.yaml` — the canonical 8-source document from docs/06 §1.
- `chronos/content/sources.py` — Pydantic `SourcesConfig` / `SourceDef` (extra=forbid), `load_sources_yaml`, and `sync_sources(session, config, now)` upsert by key (disabled keys stay in DB with `enabled=0`).
- `chronos/content/fetchers/` — `ParsedItem` dataclass and per-kind parsers (`rss`, `hf_daily_papers`, `arxiv`, `hackernews`) using `feedparser` + `selectolax`.
- `chronos/content/ingest.py` — `fetch_source` (conditional GET, 304, health columns, Algolia points lookup for HN) and `fetch_all` (failure-isolated iteration over enabled sources).
- DB migration `0004` adds `min_points` to `sources`.
- `chronos config validate` + startup lifespan + justfile `config-validate` extended to cover `sources.yaml`.
- Coverage gate extended to `chronos.http` and `chronos.content` at 85 % (wake stays 90 %).

## 2. Design

**HTTP guard**
- `httpx.AsyncClient(follow_redirects=False)` is the underlying transport.
- Before every request (and every redirect target) we resolve the hostname with an injectable `Resolver`, check every returned IP with `is_public_ip()` (`ipaddress` module: reject private/loopback/link-local/multicast/reserved, v4+v6), and raise `SsrfBlocked` pre-connect if any IP is non-public.
- Redirects are followed manually (max 3). Relative `Location` is resolved with `httpx.URL.join`.
- Body is consumed with `response.aiter_bytes()`; a running byte counter aborts past `max_bytes` and raises `TooLarge`. No `.read()` call materialises the whole body.
- Content-type header is checked against a caller-supplied allowlist before streaming begins.

**Why not a custom httpcore transport?** Full TOCTOU mitigation would require connecting to the resolved IP while pinning Host/SNI. That needs a private `httpcore` API that may break on patch releases. The design accepts the small residual TOCTOU window (documented inline) because the threat model is a single-user LAN laptop; the fake-resolver tests prove the guard logic is correct.

**Source loader**
- Mirrors `chronos/wake/rules.py`: `yaml.safe_load` → Pydantic `SourcesConfig` with `extra="forbid"`.
- Duplicate `key` in the YAML list is rejected by a `field_validator`.
- `sync_sources` updates definition fields (`kind`, `url`, `category`, `quota`, `weight`, `min_points`) by key, preserves runtime/health fields (`etag`, `last_modified`, `consecutive_failures`, …), and disables (`enabled=0`) keys that disappeared from the YAML.

**Fetchers**
- Each fetcher is a pure function `parse(body: bytes, now: str) -> list[ParsedItem]`.
- `rss.py` uses `feedparser` and `selectolax` for HTML stripping; extracts `image_url` from `media:content`, `media:thumbnail`, and `enclosures`.
- `arxiv.py` strips the `vN` version suffix from the Atom `id` URL.
- `hackernews.py` parses the RSS only; the Algolia points lookup lives in `ingest.py` so the fetcher stays pure.
- T3.2 does **not** write to the `items` table (owner decision). Golden fixtures are in-memory `ParsedItem`s.

**Ingest orchestration**
- `fetch_source` builds conditional-GET headers from the `Source` row, calls `client.fetch`, parses, does the HN Algolia lookup (5 s timeout override), applies `min_points`, and updates the DB health columns in a short transaction after the network call returns.
- `fetch_all` iterates enabled sources; one source failing raises `SourceFetchOutcome(status="error", …)` and does **not** abort the loop.

### Step 2 — SSRF-guarded HTTP client

**Files:** `src/chronos/http.py`, `tests/http/test_guarded_client.py`

**Complete code for `chronos/http.py`:**

```python
"""SSRF-guarded async HTTP client for Chronos-AI (T3.2).

Every outbound fetch goes through :class:`GuardedHttpClient`.

Security notes
--------------
- DNS is resolved *before* each request and each redirect hop via an
  injectable :data:`Resolver`.  All returned IPs are checked with
  :func:`is_public_ip`.  If any IP is non-public the request is rejected
  **before** a TCP connection is opened.
- The client does a manual redirect loop (max ``max_redirects``) so that
  every ``Location`` host is re-resolved and re-checked.
- Body bytes are streamed via ``aiter_bytes``; a running counter aborts at
  ``max_bytes``.  The response is closed after abort so the connection pool
  is not poisoned.
- Full TOCTOU mitigation (pinning the resolved IP and overriding SNI) would
  require a private ``httpcore`` API; the residual window is accepted for
  this threat model and documented here explicitly.
"""

from __future__ import annotations

import ipaddress
import time
from collections.abc import Awaitable, Callable, Mapping
from dataclasses import dataclass
from typing import Any

import httpx
import structlog

log = structlog.get_logger(__name__)

Resolver = Callable[[str], Awaitable[list[str]]]


async def _default_resolver(hostname: str) -> list[str]:
    """Resolve *hostname* to IPv4/IPv6 addresses via ``asyncio.getaddrinfo``."""
    import asyncio
    import socket

    loop = asyncio.get_running_loop()
    infos = await loop.getaddrinfo(hostname, None, proto=socket.IPPROTO_TCP)
    return [info[4][0] for info in infos]


def is_public_ip(ip_str: str) -> bool:
    """Return ``True`` only if *ip_str* is a globally routable address.

    Rejects private, loopback, link-local, multicast, and reserved ranges
    for both IPv4 and IPv6.  IPv6 unique-local (``fc00::/7``) is covered by
    ``is_private`` in Python 3.12.
    """
    try:
        ip = ipaddress.ip_address(ip_str)
    except ValueError:
        return False
    return not (
        ip.is_private
        or ip.is_loopback
        or ip.is_link_local
        or ip.is_multicast
        or ip.is_reserved
    )


# ---------------------------------------------------------------------------
# Exceptions
# ---------------------------------------------------------------------------


class FetchError(Exception):
    """Base for all fetch failures."""


class SsrfBlocked(FetchError):
    """The resolved IP was in a blocked range."""


class TooLarge(FetchError):
    """Body exceeded ``max_bytes``."""


class TooManyRedirects(FetchError):
    """More than ``max_redirects`` hops."""


class ContentTypeRejected(FetchError):
    """Response content-type not in the caller allowlist."""


class FetchFailed(FetchError):
    """Network-level failure (timeout, DNS, reset, etc.)."""


# ---------------------------------------------------------------------------
# Result
# ---------------------------------------------------------------------------


@dataclass(frozen=True, slots=True)
class FetchResult:
    """Immutable result of a successful (or 304) fetch."""

    status: int
    final_url: str
    headers: Mapping[str, str]
    body: bytes
    content_type: str
    duration_ms: float


# ---------------------------------------------------------------------------
# Client
# ---------------------------------------------------------------------------


class GuardedHttpClient:
    """Async HTTP client with SSRF guard, redirect cap, and byte limit."""

    def __init__(
        self,
        user_agent: str,
        *,
        timeout_sec: float = 15.0,
        max_bytes: int = 2_000_000,
        max_redirects: int = 3,
        resolver: Resolver | None = None,
    ) -> None:
        self.user_agent = user_agent
        self.timeout = httpx.Timeout(timeout_sec)
        self.max_bytes = max_bytes
        self.max_redirects = max_redirects
        self.resolver = resolver or _default_resolver
        self._client = httpx.AsyncClient(
            follow_redirects=False,
            timeout=self.timeout,
        )

    async def fetch(
        self,
        url: str,
        *,
        allowed_content_types: set[str] | None = None,
        headers: dict[str, str] | None = None,
        timeout_sec: float | None = None,
    ) -> FetchResult:
        """Fetch *url* with the configured guard rules.

        Args:
            url: Target URL.  Only ``http`` and ``https`` schemes are allowed.
            allowed_content_types: Lower-cased content-type values to accept,
                e.g. ``{"application/xml", "text/xml", "application/json"}``.
                If the response ``Content-Type`` (header, stripped of charset)
                is not in this set, :exc:`ContentTypeRejected` is raised.
            headers: Extra request headers merged with the default UA.
            timeout_sec: Per-request timeout override (seconds).

        Raises:
            SsrfBlocked: Resolved IP is non-public.
            TooManyRedirects: More than ``max_redirects`` hops.
            ContentTypeRejected: Content-type not in allowlist.
            TooLarge: Body exceeded ``max_bytes``.
            FetchFailed: DNS, TCP, or HTTP transport failure.
        """
        start = time.perf_counter()
        current_url = httpx.URL(url)

        if current_url.scheme not in ("http", "https"):
            raise SsrfBlocked(f"Scheme {current_url.scheme!r} not allowed")

        # Resolve and check initial host
        await self._check_host(current_url.host)

        req_headers: dict[str, str] = {"User-Agent": self.user_agent}
        if headers:
            req_headers.update(headers)

        effective_timeout = (
            httpx.Timeout(timeout_sec) if timeout_sec is not None else self.timeout
        )

        method = "GET"
        redirect_count = 0
        response: httpx.Response | None = None

        while True:
            request = self._client.build_request(
                method, current_url, headers=req_headers, timeout=effective_timeout
            )
            try:
                response = await self._client.send(request, stream=True)
            except (httpx.TimeoutException, httpx.ConnectError, httpx.NetworkError) as exc:
                raise FetchFailed(f"Transport error for {current_url.host}: {exc}") from exc

            # Redirect handling
            if 300 <= response.status_code < 400:
                if redirect_count >= self.max_redirects:
                    await response.aclose()
                    raise TooManyRedirects(
                        f"Exceeded {self.max_redirects} redirects"
                    )
                location = response.headers.get("location")
                await response.aclose()
                if not location:
                    raise FetchFailed("Redirect with no Location header")
                current_url = current_url.join(location)
                if current_url.scheme not in ("http", "https"):
                    raise SsrfBlocked(f"Redirect scheme {current_url.scheme!r} not allowed")
                await self._check_host(current_url.host)
                redirect_count += 1
                continue

            break

        assert response is not None

        # Content-type check before streaming body
        raw_ct = response.headers.get("content-type", "")
        ct = raw_ct.split(";")[0].strip().lower()
        if allowed_content_types is not None and ct not in allowed_content_types:
            await response.aclose()
            raise ContentTypeRejected(
                f"Content-Type {ct!r} not in {allowed_content_types}"
            )

        # Stream body with byte cap
        body = bytearray()
        try:
            async for chunk in response.aiter_bytes():
                if len(body) + len(chunk) > self.max_bytes:
                    raise TooLarge(
                        f"Body exceeded max_bytes ({self.max_bytes})"
                    )
                body.extend(chunk)
        finally:
            await response.aclose()

        duration_ms = (time.perf_counter() - start) * 1000.0

        return FetchResult(
            status=response.status_code,
            final_url=str(current_url),
            headers=dict(response.headers),
            body=bytes(body),
            content_type=ct,
            duration_ms=duration_ms,
        )

    async def _check_host(self, host: str) -> None:
        """Resolve *host* and raise :exc:`SsrfBlocked` if any IP is non-public."""
        try:
            ips = await self.resolver(host)
        except Exception as exc:
            raise FetchFailed(f"DNS resolution failed for {host}: {exc}") from exc
        if not ips:
            raise FetchFailed(f"No DNS results for {host}")
        for ip in ips:
            if not is_public_ip(ip):
                raise SsrfBlocked(
                    f"Host {host!r} resolved to blocked IP {ip}"
                )
```

```python
from __future__ import annotations

import json
from pathlib import Path
from typing import Any

import yaml
from pydantic import BaseModel, ConfigDict, Field, ValidationError, field_validator
from sqlmodel import Session, select

from chronos.enums import ContentCategory, SourceKind
from chronos.models.content import Source
from chronos.time import utc_now_iso

class HttpConfig(BaseModel):
    model_config = ConfigDict(extra="forbid")
    user_agent: str
    timeout_sec: float = Field(default=15.0, gt=0.0)
    max_bytes: int = Field(default=2_000_000, gt=0)

    model_config = ConfigDict(extra="forbid")

    category_min: dict[str, int]
    freshness_hours: int = Field(default=20, ge=1)

class SourceDef(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)
    key: str
    kind: SourceKind
    url: str
    category: ContentCategory

    weight: float = Field(default=1.0, ge=0.0)

class SourcesConfig(BaseModel):
    model_config = ConfigDict(extra="forbid")
    version: int
    http: HttpConfig
    sources: list[SourceDef]
    selection: SelectionConfig

    @field_validator("sources", mode="after")
    @classmethod
    def _no_duplicate_keys(cls, v: list[SourceDef]) -> list[SourceDef]:
        seen: set[str] = set()
        for s in v:
            if s.key in seen:
                raise ValueError(f"duplicate source key: {s.key}")
            seen.add(s.key)
        return v

def load_sources_yaml(path: Path) -> SourcesConfig:
    raw = yaml.safe_load(path.read_text(encoding="utf-8"))
    return SourcesConfig.model_validate(raw)

def sync_sources(session: Session, config: SourcesConfig, now: str) -> None:
    existing = {s.key: s for s in session.exec(select(Source)).all()}
    config_keys = {d.key for d in config.sources}
    for d in config.sources:
        row = existing.get(d.key)
        if row is None:
            row = Source(
                key=d.key,
                kind=d.kind.value,
                url=d.url,
                category=d.category.value,
                quota=d.quota,
                weight=d.weight,
                min_points=d.min_points,
                enabled=1,
            )
            session.add(row)
        else:
            row.kind = d.kind.value
            row.url = d.url
            row.category = d.category.value
            row.quota = d.quota
            row.weight = d.weight
            row.min_points = d.min_points
            row.enabled = 1
    for key, row in existing.items():
        if key not in config_keys and row.enabled == 1:
            row.enabled = 0
```

### Step 5 — Ingest orchestration

**Files:** `src/chronos/content/ingest.py`, `tests/content/test_ingest.py`

**Public interface:**

```python
@dataclass(frozen=True, slots=True)
class SourceFetchOutcome:
    source_key: str
    status: str          # "ok", "not_modified", "error"
    items: list[ParsedItem]
    error: str | None = None

@dataclass(frozen=True, slots=True)
class IngestReport:
    outcomes: list[SourceFetchOutcome]
    total_items: int

async def fetch_source(
    client: GuardedHttpClient,
    source: Source,
    config: SourcesConfig,
    now: str,
) -> SourceFetchOutcome: ...

async def fetch_all(
    client: GuardedHttpClient,
    session: Session,
    config: SourcesConfig,
    now: str,
) -> IngestReport: ...
```

**Key logic for `fetch_source`:**
1. Build conditional-GET headers from `source.etag` / `source.last_modified`.
2. Call `client.fetch(source.url, allowed_content_types=FEED_CONTENT_TYPES, headers=req_headers)`.
3. If 304 → update `source.last_fetched_at = now`, `source.last_status = "304"`, `source.consecutive_failures = 0`, `session.add(source); session.commit()`; return `SourceFetchOutcome(source.key, "not_modified", [])`.
4. On `FetchError` → `source.consecutive_failures += 1`, `source.last_error = str(exc)[:500]`, `source.last_status = type(exc).__name__`, `source.last_fetched_at = now`, commit; return `SourceFetchOutcome(source.key, "error", [], error=...)`.  (Never re-raise.)
5. On 200 → parse with kind-specific parser.
6. If `source.kind == "hn_rss"` → for each item, try Algolia lookup (`client.fetch(..., timeout_sec=5.0)`).  On any exception → accept item, note `points: null` in `extra_json`.  If points known and `source.min_points` is set and points < min_points → skip item.
7. Update health: `last_fetched_at = now`, `last_status = "200"`, `consecutive_failures = 0`, `etag = result.headers.get("etag")`, `last_modified = result.headers.get("last-modified")`, commit.
8. Return `SourceFetchOutcome(source.key, "ok", items)`.

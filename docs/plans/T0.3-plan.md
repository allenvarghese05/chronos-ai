# T0.3 Plan: API scaffold `services/api`

## 1. Summary

Creates the complete `services/api` Python 3.12 scaffold that all later tasks depend on.
When done: `just check-api` is green (ruff, format, pyright strict, pytest ≥5 tests, bandit);
`uv run chronos serve` starts a uvicorn server that answers `/healthz` and `/readyz`;
`chronos config validate --help` exits 0; `uv sync --locked` works from a clean checkout with
committed `uv.lock`.

## 2. Design

**App factory + Typer CLI**: `create_app()` in `chronos.main` returns a FastAPI instance;
`chronos` CLI via Typer wraps it with `serve`, `db migrate`, `config validate`, `doctor`.

**Sync SQLAlchemy engine**: Owner answer (2): sync engine, PRAGMAs via `connect` event, temp-file
DB in tests (never `:memory:`).

**TLS**: Owner answer (1): uvicorn built-in `ssl_certfile/ssl_keyfile`; plain HTTP only when
`CHRONOS_ENV` is `dev` or `test`; missing cert in `prod` is a startup error.

**Structlog JSON**: Configured once in `observability.configure()` before app creation; redacts
`token`, `sig`, `authorization`, `secret` keys; dev=stdout, prod=file.

**No CORS**: Owner answer (4): no CORS middleware.

**Rejected alternatives**:
- Async SQLAlchemy: deferred to after T0.3 (sync is simpler, sufficient for single-process).
- Hypercorn: uvicorn chosen (D16, owner answer 1).
- freezegun: time-machine only (owner answer 3).

from sqlmodel import SQLModel

def _apply_pragmas(dbapi_conn: sqlite3.Connection, _connection_record: ConnectionPoolEntry) -> None:
    """Set WAL mode, foreign keys, and busy_timeout on every new connection."""
    ...

def create_db_engine(database_url: str) -> Engine:
    """Create a sync SQLAlchemy engine with PRAGMAs wired to the connect event."""
    engine = create_engine(database_url, connect_args={"check_same_thread": False})
    event.listen(engine, "connect", _apply_pragmas)
    return engine

def build_migration_engine(database_url: str) -> Engine:
    """Create a NullPool engine for Alembic migrations, with PRAGMAs applied."""
    engine = create_engine(database_url, connect_args={"check_same_thread": False}, poolclass=NullPool)
    event.listen(engine, "connect", _apply_pragmas)
    return engine

def get_session(engine: Engine) -> Generator[Session, None, None]:
    """Yield a session; roll back on exception, close on exit."""
    ...

_engine: Engine | None = None

def get_engine() -> Engine: ...

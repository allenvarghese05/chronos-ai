# T0.1 Plan: Repo skeleton – verify, hook additions, first clean run

## 1. Summary

T0.1 is a verification and hardening task.  All skeleton files already exist on the
`t0-1-repo-skeleton` branch.  This plan installs the required tools (`just setup`,
`brew install gitleaks`), adds the two generic pre-commit hooks that the owner approved
(`trailing-whitespace`, `end-of-file-fixer`) as local bash hooks (consistent with the
"local hooks only" policy), runs `pre-commit run --all-files` and `just security` to
find and fix any formatting / whitespace regressions, and confirms `just check` exits 0.

## 2. Design

**Approach:** implement the two new hooks as `local` repo entries in `.pre-commit-config.yaml`
so no external `pre-commit-hooks` mirror is needed.  Each hook is a one-liner bash entry
command; `language: system` keeps them consistent with the other hooks in the file.

Rejected alternatives:
- Use `repo: https://github.com/pre-commit/pre-commit-hooks` – violates "local hooks only" policy.
- Write wrappers in `scripts/` – unnecessary; the one-liner fits inline and is simpler.

### Step 3 – Add `trailing-whitespace` and `end-of-file-fixer` local hooks

**Files touched:** `.pre-commit-config.yaml`

**Change:** append two hooks to the existing `local` repo block:

```yaml
      - id: trailing-whitespace
        name: trailing whitespace
        entry: bash -c 'for f in "$@"; do sed -i "" "s/[[:space:]]*$//" "$f"; done' --
        language: system
        types: [text]

      - id: end-of-file-fixer
        name: end of file fixer
        entry: bash -c 'for f in "$@"; do tail -c1 "$f" | read -r _ || echo >> "$f"; done' --
        language: system
        types: [text]
```

These hooks auto-fix files in place.  A first pre-commit run will fix, then the developer
stages and re-runs; CI always sees clean files.

**Tests:** run `pre-commit run trailing-whitespace --all-files` and
`pre-commit run end-of-file-fixer --all-files` separately to confirm each finds and fixes
its target class of issues.

**Verify:**
```bash

```
Passing: all hooks exit 0 (after any auto-fixes are staged and re-run).
